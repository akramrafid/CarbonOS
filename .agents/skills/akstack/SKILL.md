# CarbonOS Bangladesh — Orchestration Skill (akstack)

## Overview
Akram-Stack (`akstack`) is the autonomous engineering spine governing **CarbonOS Bangladesh** (Sovereign Climate-Tech & Enterprise ESG SaaS Operating System). It maintains deterministic project continuity across multi-week sessions by persisting state on disk:
- `plan.md` (domain hard rules, system architecture, C4 boundaries, SLO budgets),
- `PRODUCT.md` (exhaustive product specification & regulatory references),
- `ToDos.md` (the machine-parsable task ledger),
- `PROGRESS.md` (the append-only engineering journal),
- `agents/` (42 specialized role briefs, each with isolated file boundaries and handoffs),
- `orchestrator/` & `bin/akstack` (zero-dependency Python CLI engine for DAG resolution, conflict-free parallel wave scheduling, task transitions, and automated gating).

You are the **coordinator** unless a specific task Owner is declared. Orient from disk. Do not rely on conversational context.

## Session Execution Loop

```bash
# 1. Inspect next actionable task
python -m orchestrator.cli next

# 2. Extract full machine-readable execution packet
python -m orchestrator.cli packet

# 3. Claim and start task execution
python -m orchestrator.cli start <task-id>

# 4. Implement strictly within declared Files:; review agents/<owner>.md first
# 5. Complete task (verifies exit code 0, writes journal entry, stages files)
python -m orchestrator.cli complete <task-id>
```

* **Parallel Waves**: Disjoint files only: `python -m orchestrator.cli next --parallel`.
* **Human Escalation**: `python -m orchestrator.cli handoff <id> --blocked-on "..." --why "..."` then halt.
* **Resume after Resolution**: `python -m orchestrator.cli resume --notes "..."`.
* **Domain Ambiguity**: `python -m orchestrator.cli question <id> --ambiguity "..." --risk "..." --recommended "..."`.
* **Task Failure & Reset**: `python -m orchestrator.cli fail <id> --error "..."` then later `reset`.

## CarbonOS Domain Hard Rules

All agents operating in this repository must strictly enforce these six non-negotiable invariants:

1. **DoE Grid Emission Factor Lock**: All Scope 2 location-based calculations must strictly use the official Bangladesh Department of Environment & SREDA Combined Margin factor of **`0.550 kg CO₂e / kWh`** (Gazette Ref: `22.02.0000.018.99.001.23`). Hardcoding alternative foreign grid factors is a P0 regression.
2. **Multi-Tenant Vector Isolation**: In the ChromaDB vector store and RAG retrieval pipelines, private tenant documents, factory bills, and audit statements must be segregated by `tenant_id`. Every similarity query must execute with `where={"tenant_id": current_tenant}`. Cross-tenant leakage is strictly prohibited.
3. **Verifiable RAG Grounding**: Every regulatory citation generated by the AI copilot must contain the exact document title, page number, and verbatim snippet. If retrieved context confidence is below `0.60`, a structured data-insufficiency disclaimer must be emitted instead of hallucinating.
4. **Satellite MRV Hash Reproducibility**: All Sentinel-2 vegetation and carbon credit estimates must record sensor acquisition timestamp, cloud-cover threshold, geometry GeoJSON, and model weights hash.
5. **Zero Mandatory Tooling Cost**: The platform must remain fully functional with $0 in mandatory recurring API fees, providing local deterministic rule-based fallbacks for AI synthesis and open-source local vector search.
6. **Dual-Theme Design Token Contract**: Any new UI components must strictly support both the primary Obsidian Dark Theme (`#040906`, `#00C853`) and the 5-Color Mint Light Theme (`#E6F5E2`, `#A4E3A4`, `#B4D44D`, `#337738`, `#282900`). Hardcoded un-themed colors are forbidden.
