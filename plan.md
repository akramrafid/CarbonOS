## 1. What & Why

**CarbonOS Bangladesh** is the nation's premier sovereign climate-tech operating system. It bridges grassroots rural emissions reduction projects (solar irrigation, alternate wetting and drying rice methane reduction, clean cookstoves, blue carbon) with enterprise corporate carbon accounting, providing an auditable multi-corpus RAG copilot, real-time IoT sensor telemetry, dual-reporting Scope 2 disclosures, and an Article 6-aligned carbon credit registry.

* **Primary User Outcome**: Verifiable, audit-ready corporate ESG disclosures and automated carbon footprint extraction paired with verified local credit generation.
* **Commercial Model**: SaaS subscription tier (Enterprise ESG Dashboard) + transaction fee on secondary carbon credit retirements and registry onboarding.
* **Acquisition Surfaces**: Public marketing landing page (`/`), methodology framework documentation (`/company/framework-docs`), marketplace browse directory (`/platform/marketplace`), and API documentation (`/company/api-docs`).
* **North-Star Metric**: Audited metric tons of CO₂e verified and retired on the sovereign Bangladesh carbon registry.

| Role | Permissions & Capabilities | System Boundaries & Constraints |

| **Public Buyer / Trader** | Browse verified credit marketplace, inspect satellite MRV trails, purchase/retire credits | Cannot access confidential corporate billing or tenant-specific activity data |

## 3. Domain Hard Rules

1. **DoE Grid Emission Factor Lock**: All Scope 2 location-based calculations must strictly utilize the Bangladesh Department of Environment & SREDA Combined Margin factor of **`0.550 kg CO₂e / kWh`** (Gazette Ref: `22.02.0000.018.99.001.23`).
2. **Multi-Tenant Vector Isolation**: In the ChromaDB vector store and RAG retrieval pipelines, private tenant documents, factory bills, and audit statements must be segregated by `tenant_id`. Queries must enforce `where={"tenant_id": current_tenant}`. Cross-tenant vector leakage is a P0 security defect.
3. **Verifiable RAG Grounding**: Every regulatory citation generated by the AI copilot must contain the exact document title, page number, and verbatim snippet. If retrieved context confidence is below `0.60`, a structured data-insufficiency disclaimer must be emitted instead of hallucinating.
4. **Dual-Reporting Scope 2**: Scope 2 electricity disclosures must calculate and display both location-based (`0.550 kg CO₂e/kWh`) and market-based (contractual PPA/green tariff) figures per GHG Protocol Scope 2 Guidance.
5. **Satellite MRV Reproducibility**: All Sentinel-2 vegetation and carbon credit estimates must record sensor acquisition timestamp, cloud-cover threshold, geometry GeoJSON, and model weights hash.
6. **Zero Mandatory Tooling Cost**: The platform must operate with $0 in mandatory recurring API fees, providing local deterministic rule-based fallbacks for AI synthesis and open-source local vector search.
7. **Dual-Theme Design Token Contract**: Any new UI components must strictly support both the primary Obsidian Dark Theme (`#040906`, `#00C853`) and the Light Theme UI Foundations (`#f2f3ee`, `#dbf0ea`, `#413f3f`, `#181414`, `#ffffff`, `Helvetica, Arial, sans-serif`, `shadow.1`).

```
                          ┌──────────────────────────────────────┐

                                              │
                    ┌─────────────────────────┴─────────────────────────┐
                    ▼                                                   ▼
┌────────────────────────────────────────┐          ┌────────────────────────────────────────┐
│  Inference Service: FastAPI (:8000)    │          │  Django Backend Service (:8001)        │
│  - esg_rag router (ChromaDB + Gemini)  │          │  - farmers_ai app (Risk Engine)        │
│  - carbon_monitoring router (Blynk IoT)│          │  - SQLite3 / PostgreSQL audit ledger   │
│  - PyTorch CNN (EfficientNet-B3)       │          │  - Django Channels (WebSockets)        │

```

* **Frontend**: React 19, Vite, Tailwind CSS v3.4, Lucide Icons, Framer Motion, GSAP, Leaflet / React-Leaflet, i18next.
* **Backend API**: Python 3.13, FastAPI, Uvicorn, SQLAlchemy, SQLite3 / PostgreSQL, ChromaDB, PyTorch, Torchvision, OpenCV.
* **AI & RAG Engine**:
  * Dense vector embeddings: `sentence-transformers/all-MiniLM-L6-v2` (384 dimensions).
  * High-speed reasoning: Google Gemini 2.5 Flash with prompt-grounded citation extraction.
  * Deterministic fallback synthesizer: Rule-based regex & semantic keyword matcher for offline reliability.
  * Multi-Head Crop Diagnosis: PyTorch CNN (EfficientNet-B3 backbone) with Grad-CAM visual saliency mapping across 41 disease classes for 8 Bangladesh crops.
* **IoT Hardware Telemetry**:
  * Blynk Cloud REST & WebSocket API interfacing with industrial ESP8266/ESP32 nodes.
  * Time-series capture of exhaust temperature, ambient humidity, and gas concentration (ppm).
* **Design Engine**:
  * Dual-theme token architecture: Obsidian Dark (`#040906`, `#00C853`) and Light Theme UI (`#f2f3ee`, `#dbf0ea`, `#413f3f`, `#181414`, `Helvetica`).
  * Custom SVG charting: Semi-Circular Gauge, 12-Month Catmull-Rom Trend Chart, Segmented Progress Bars.

## 5. Data & Storage Invariants

* **Auditability**: Append-only query and extraction logs (`esg_query_logs`) tracking model used, query string, retrieved chunks, user ID, and latency.
* **Multi-Corpus Segregation**: Partitioning vectors into `regulatory` (public), `emission_factors` (verified), and `tenant_docs` (private per tenant).
* **Credit Ledger Immutability**: Carbon credit retirements write a permanent, tamper-evident hash to the registry database, invalidating the serial range from future trade.

## 6. Service Level Objectives (SLOs) & Performance Budgets

* **Vector Retrieval Latency**: P95 < 250ms across 10,000 document chunks.
* **Full RAG Generation Latency**: P95 < 1.8s (online with Gemini) / P95 < 80ms (local rule fallback).
* **Core Web Vitals**:
  * Largest Contentful Paint (LCP) < 2.5s.
  * Interaction to Next Paint (INP) < 150ms.
  * Cumulative Layout Shift (CLS) < 0.05.
* **Availability**: 99.9% target uptime.
* **Accessibility**: WCAG 2.2 AA compliance across all routes.
