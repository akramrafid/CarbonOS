## 1. RAG Architecture Overview

The CarbonOS ESG RAG engine (`inference/esg_rag/retriever.py`) provides evidence-grounded answers to regulatory, compliance, and carbon accounting inquiries.

```
[ User Query + Tenant ID ]
           │
           ▼
[ Query Embedding (Gemini / Sentence-Transformers) ]
           │
           ▼
[ ChromaDB Multi-Collection Vector Search with Strict Tenant Filter ]
   ├─ Public Shared Corpora:
   │    • Bangladesh DoE Official Gazette Notifications
   │    • SREDA Grid Emission Factors & Combined Margin Ref
   │    • Verra VM0047 Afforestation / Reforestation Methodologies
   │    • EU CBAM Textile Sector Compliance Guidance
   └─ Private Tenant Corpus:
        • Facility Invoices & Audited Statements (Isolated by tenant_id)
           │
           ▼
[ Reranker & Context Formatter with Page-Level Citations ]
           │
           ▼
[ Gemini LLM with Strict System Prompt & Grounding Invariants ]
           │
           ▼
[ Synthesized Response with Verbatim Source Excerpts & Confidence Score ]
```

## 2. Benchmark Evaluation Suite (`ATLAS`)

The RAG engine is continuously validated using the automated `ATLAS` benchmark suite (`inference/esg_rag/atlas_benchmark.py`).

### 2.1 Evaluated Dimensions
1. **Parameter Accuracy:** Correct identification and extraction of numerical values (kWh, Liters, kg CO₂e).
2. **Scope Classification:** Precise mapping of activities into Scope 1, Scope 2, or Scope 3 categories according to the GHG Protocol.
3. **Citation Faithfulness:** Presence of exact page numbers, gazette references, and document titles.
4. **Abstention on Out-of-Corpus Queries:** Explicit refusal to fabricate responses when regulatory evidence is absent.

## 3. Tenant Boundary & Isolation (Scenario B Verification)

- **Security Rule:** A query from `tenant_id="tenant-rmg-01"` must never return snippets or citations from documents owned by `tenant_id="tenant-textile-02"`.
- **Implementation:**
  - `_build_tenant_filter(tenant_id)` constructs an explicit boolean clause passed to ChromaDB:
    `{"$or": [{"tenant_id": current_tenant}, {"tenant_id": "public"}]}`
  - If a query is submitted with an empty or missing `tenant_id`, the retriever strictly queries public regulatory documents only and completely excludes tenant-uploaded files.
- **Verification Evidence:** `tests/test_tenant_isolation.py` (4/4 test cases passing):
  - `test_cross_tenant_document_query_isolation`: PASS
  - `test_public_corpora_shared_across_tenants`: PASS
  - `test_tenant_isolation_in_fallback_retrieval`: PASS
  - `test_tenantless_query_cannot_access_tenant_docs`: PASS

## 4. Prompt Injection & Anti-Hallucination Guardrails

1. **System Prompt Constraint:** Gemini prompt enforces verbatim excerpting and explicitly forbids answering queries unsupported by the retrieved snippets.
2. **Abstention Phrase:** When evidence is insufficient, the system emits:
   `"প্রদত্ত সরকারি গেজেট বা নথিপত্রে এই তথ্যের স্পষ্ট উল্লেখ পাওয়া যায়নি। অনুগ্রহ করে পরিবেশ অধিদপ্তর (DoE) অথবা অনুমোদিত অডিটরের সাথে যোগাযোগ করুন।"`
3. **No Unwarranted Certification:** Answers generated by Gemini are clearly labeled as AI synthesis based on indexed reference texts, and are never marked as legally certified without human auditor review.
